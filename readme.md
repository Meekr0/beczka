
### Setup Virtual Environment

1. Create a virtual environment:
   ```bash
   python -m venv venv
   ```

2. Activate it:
   - **Windows**:
     ```bash
     venv\Scripts\activate
     ```
   - **macOS/Linux**:
     ```bash
     source venv/bin/activate
     ```

<h3>Install Dependencies</h3>

```bash
pip install -r requirements.txt
```

<h3> Run </h3>

```python
python main.py
```
